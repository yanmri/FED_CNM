# FED_CNM
Extracted peak coordinates and NIfTI-format network maps from the study "Network-Level Convergence of Functional and Structural Alterations in First-Episode Major Depressive Disorder."

Table 1 shows the coordinates (in MNI space) of significant clusters identified in resting-state activity studies.
Table 2 shows the coordinates (in MNI space) of significant clusters identified in gray matter volume studies.
FED-associated network probability map_functional.nii is the derived FED-associated probability map from the functional modality.
FED-associated network probability map_structural.nii is the derived FED-associated probability map from the structural modality.
FED-associated network_functional_0.5.nii is the identified FED-associated network from the functional modality and applied 50% as threshlod.
FED-associated network_functional_0.5_binary mask.nii is the identified FED-associated network show in the binary map (the value of the voxles which belong to the netwrok is 1 and other voxels is 0).
FED-associated network_structural_0.5.nii is the identified FED-associated network from the structural modality and applied 50% as threshlod.
FED-associated network_structural_0.5_binary mask.nii is the identified FED-associated network show in the binary map (the value of the voxles which belong to the netwrok is 1 and other voxels is 0).
